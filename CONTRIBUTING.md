# Contributing

Contributions are welcome.

Useful contributions include:

- better research-evaluation prompts
- paper-search workflows
- reproducibility checklists
- benchmark/evaluation templates
- tool comparisons
- examples showing how an Idea changed after adversarial review

Please avoid:

- unverified claims about tools
- fabricated citations
- ranking research ideas using only a single LLM score
- prompts that encourage overstating experimental conclusions
