# Skill: Hypothesis Generator

## Goal
生成可证伪，而非“听起来有趣”的假设。

## Prompt

```text
Generate 10 falsifiable hypotheses based on the supplied evidence.

For each hypothesis provide:

Hypothesis
Mechanism
Supporting evidence
Contradicting evidence
Experiment
Control
Metric
Expected result
Falsification condition
Estimated compute
Main confounder

Prefer hypotheses that can be killed cheaply.
Avoid hypotheses whose only evaluation is downstream benchmark improvement.
```
