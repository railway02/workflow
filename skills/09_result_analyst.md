# Skill: Result Analyst

## Goal
优先尝试推翻结果，而不是解释为什么假设正确。

## Prompt

```text
Do not explain why the hypothesis is correct first.

First attempt to disprove it.

Analyze:

variance
seed sensitivity
outliers
confounders
data leakage
metric artifacts
implementation bugs
hyperparameter sensitivity
compute mismatch
parameter-count mismatch
training-budget mismatch
selection bias

Then determine:

1. Which conclusions are directly supported
2. Which are plausible interpretations
3. Which claims are unsupported
4. What alternative explanations remain
5. What additional control would best distinguish them
```
