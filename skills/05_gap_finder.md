# Skill: Gap Finder

## Goal
从证据中找研究 Gap，而不是凭空 brainstorm。

## Prompt

```text
Do NOT brainstorm novel ideas immediately.

First identify:

- contradictory findings
- missing baselines
- uncontrolled variables
- dataset bias
- benchmark saturation
- unrealistic assumptions
- missing ablations
- scalability limitations
- compute bottlenecks
- deployment constraints
- unexplained empirical phenomena

For each candidate gap:

1. Evidence that the gap exists
2. Closest prior work
3. Why existing work does not already solve it
4. A falsifiable hypothesis
5. Smallest validation experiment
6. What result would eliminate the gap as interesting
```
